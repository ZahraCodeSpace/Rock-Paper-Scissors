## 🕹️ How to Play

1. Choose your move: Rock, Paper, or Scissors.
2. The computer randomly selects its move.
3. The game compares both choices and determines the round winner.
4. The scoreboard updates after each round.
5. The first player to reach **5 points** wins the game!

### Game Rules

| Your Move | Beats |
|:---:|:---:|
| 🪨 Rock | ✂️ Scissors |
| 📄 Paper | 🪨 Rock |
| ✂️ Scissors | 📄 Paper |

If both players choose the same move, the round ends in a draw.

## 🚀 Getting Started

Want to run the game on your own computer?

### Clone the Repository

```bash
git clone https://github.com/ZahraCodeSpace/Rock-Paper-Scissors.git
```

### Open the Project

```bash
cd Rock-Paper-Scissors
```

Open the project in your code editor and launch `index.html` using your browser or Live Server.

No backend is required to play the game.
